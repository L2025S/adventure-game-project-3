Adventure Game – Java OOP Project
This project is a text‑based adventure game built in Java, showcasing strong object‑oriented design, clean architecture, and interactive gameplay.
The player explores different rooms, makes choices, competes in challenges, and collects points while progressing through the game world.
The project demonstrates:
• Object‑oriented programming (inheritance, abstraction, polymorphism)
• Builder pattern for character creation
• Room‑based game architecture
• State management through the Player class
• Separation of concerns (UI, model, service, DAO)
• File‑based statistics storage
• Interactive console UI
