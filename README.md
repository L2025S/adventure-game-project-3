Adventure Game – Java OOP Project <br>
This project is a text‑based adventure game built in Java, showcasing strong object‑oriented design, clean architecture, and interactive gameplay. <br>
The player explores different rooms, makes choices, competes in challenges, and collects points while progressing through the game world. <br>
The project demonstrates: <br>
• Object‑oriented programming (inheritance, abstraction, polymorphism) <br>
• Builder pattern for character creation <br>
• Room‑based game architecture <br>
• State management through the Player class <br>
• Separation of concerns (UI, model, service, DAO) <br>
• File‑based statistics storage <br>
• Interactive console UI <br>
